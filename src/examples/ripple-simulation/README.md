# Ripple Simulation

ping-pong FBO で波動方程式を回す水面シミュレーション。距離から `sin` を出す「見た目だけの波紋」ではなく、
**前フレームの状態から次フレームを計算する**ため、波が実際に伝播し、端で反射し、互いに干渉して減衰する。

## 仕組み

状態テクスチャは R に現在の高さ、G に 1 フレーム前の高さを持つ。

```
next = (north + south + east + west) * 0.5 - prev
next *= damping
```

これは波動方程式 `∂²h/∂t² = c²∇²h` を離散化したもの。ラプラシアンを 4 近傍で近似し、
`prev` を引くことで 2 階の時間微分になる。

```
targetA ──sim──▶ targetB ──render──▶ 画面
   ▲                 │
   └─── swap ────────┘
```

- FBO は `HalfFloatType`（高さは負値を取るため）、解像度は画面の 1/2
- 端は `ClampToEdge` なので、隣接サンプルが端で自分自身と同じ値になり、そのまま**反射境界**として働く
- 描画側は高さの勾配 `(hx, hy)` から法線を作り、背景テクスチャの UV をずらして屈折させる

## 入力

- **ポインタ** — 動いたフレームだけ注入。移動速度に応じて振幅が変わる
- **auto rain** — 一定間隔でランダムな位置に雨粒を落とす。放置していても動きが見える

## variant

| id | 内容 |
| --- | --- |
| `water` | 市松模様を屈折。歪みが最も読み取りやすい |
| `chrome` | 下地を暗く落としスペキュラとリムを強調した液体金属 |
| `prism` | RGB を別々の量だけずらす色収差つき屈折 |
| `field` | 高さフィールドを暖色／寒色で直接可視化。波の伝播そのものが見える |

## パラメータ

- `damping` — 1 に近いほど波が長く残る。0.999 付近でほぼ減衰しない
- `force` / `radius` — 注入する波の振幅と広がり
- `refraction` — 高さの勾配を UV オフセットに変換する量
- `dispersion` — `prism` での RGB のずれ量
- `texScale` — 背景テクスチャの繰り返し

## 実装メモ

- テクスチャは外部アセットを使わず Canvas2D で生成している（`textures.js`）
- 注入時に `uAspect` で座標を補正しないと、非正方形の FBO では波紋が楕円になる
- `next` を `clamp(-2, 2)` しているのは、`damping` を 1 に近づけたときの発散を防ぐため
- 合成・シミュレーションとも three の `FullScreenQuad` で明示的に描画する。
  R3F の自動レンダリングに任せると `setRenderTarget` を跨いだときに描画されないことがある
