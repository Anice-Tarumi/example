# Custom Cursor

canvas 2D で描くカスタムカーソル。この showcase で **WebGL を使わない唯一の example**。

元ネタは makemepulse 2019（Nomadic Tribe）。
サイト全体の「何ができるか」を 1 点に集約する設計で、画面に UI ラベルを置かずに操作を伝えている。

## 持ち帰るべき型は 3 つ

### 1. 状態はスタックで持つ

```js
pushState(s)      // 積む
releaseState(s)   // 同名が複数あっても、最後に積まれた 1 件だけ抜く
getCurrentState() // 一番上
```

「ドラッグ領域の上にリンクが重なっている」という状況で、
リンクから外れたら**自動的にドラッグ状態へ戻る**。

フラグを複数持って最終状態を計算する方式だと、
入れ子や離脱順の組み合わせで簡単に壊れる。スタックなら壊れない。

`releaseState` は必ず「最後の 1 件だけ」抜くこと。同名を全部消すとネストが壊れる。
遷移アニメーション中は `lock()` で凍結する。

### 2. 全パラメータを「現在値 / 目標値 + 共通ダンピング」で持つ

```js
this._scale = 0;  this.targetScale = 0;   // 大きさ
this._morph = 0;  this.targetMorph = 0;   // 円 ⇔ 楕円
this._ring  = 0;  this.targetRing  = 0;   // 進捗リング
this.damping = 0.12;                      // 全部これで繋ぐ
```

状態が変わったら**目標値だけ書き換える**。補間は共通のダンピングに任せる。
イージング関数もタイムラインも要らないし、途中で状態が変わっても飛ばない。

### 3. 形のモーフは SVG の等間隔サンプル

```js
const total = path.getTotalLength()
for (let i = 0; i < subdiv; i++) {
  const p = path.getPointAtLength((i / subdiv) * total)   // 等間隔に取る
  ovalPos[i * 2]     = (p.x - size / 2) * dpr * ovalScale
  ovalPos[i * 2 + 1] = (p.y - size / 2) * dpr * ovalScale
}
```

円と同じ頂点数に落としてしまえば、あとは `lerp` するだけで任意形状へモーフできる。
**デザイナーが Illustrator で描いた SVG をそのまま使える**のが利点。

この example はアセットを持たない方針なので、パス文字列を手続きで作って
同じ `getPointAtLength` に通している。実案件では `d` を差し替えるだけ。

## 手描き風の輪郭

頂点を微小にずらすが、`Math.random()` は使わない。

```js
x += (0.35 * Math.cos(39847239487 * i) - 0.175) * dpr
y += (0.35 * Math.sin(392847329847 * i) - 0.175) * dpr
```

巨大な係数を掛けた cos/sin で疑似乱数を作ると、**毎フレーム同じ位置に同じブレ**が出る。
「手で描いた線」に見えて、しかもチラつかない。`Math.random()` だと毎フレーム暴れる。

塗りは紙目のパターン。ここでは決定論的なノイズで手続きに焼いている。

## なぜ canvas 2D を選ぶか

DOM + CSS では作れないものが数十行で書ける。

- 手描きのブレた輪郭
- 紙テクスチャの塗り
- 任意パスへのモーフ

150×150 の canvas 1 枚なので負荷はほぼゼロ。WebGL を立てる必要もない。

## 落とし穴

- **`cursor: none` はデモ領域の中だけに閉じる。** ページ全体で消すと、
  描画に失敗したときに操作不能になる。実案件では「デスクトップ判定 + 描画準備完了」の
  両方を条件にすること。タッチ端末では意味がない。
- DPR は `canvas.width = w * dpr` / `style.width = w + 'px'` で確保し、
  描画座標と線幅の両方に `* dpr` を掛ける。
- 領域から出たら `reset()` する。押しっぱなしのまま外へ出て状態が残るのを防ぐ。

## 操作

- 4 つの領域にホバーすると状態が変わる
- 右下のテキスト内のリンクに乗せると状態が**積み重なる**。外すと文字の状態へ戻る
- HOLD の領域を押し続けると進捗リングが回る
