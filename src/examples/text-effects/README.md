# Text Effects

SDF フォントアトラスを**実行時に焼いて**、テキストをシェーダーで描く。
外部アセットは持たない。ブラウザにあるフォントをそのまま距離場にする。

## なぜ距離場にするのか

ビットマップの文字を拡大すればぼける。ベクタなら綺麗だが GPU で扱いにくい。

距離場は「輪郭からどれだけ離れているか」を持つ。テクスチャを線形補間しても
その値は距離として意味が通るので、**閾値で切り直せば任意の倍率で鋭い輪郭が出る**。

閾値の幅には `fwidth(d)` を使う。これは「この画素で距離が何だけ変化するか」なので、
拡大率が変わっても縁の太さがピクセル単位で一定に保たれる。

```glsl
float d    = texture2D(uAtlas, vUv).r;
float px   = fwidth(d) * uSoft;
float fill = smoothstep(edge - px, edge + px, d);
```

塗り・縁取り・グローは、同じ距離場を違う閾値で切るだけで出せる。

## 焼き方

1. グリフを 1 文字ずつセルに `fillText`
2. アルファを 2 値化して内外のマスクにする
3. 内側・外側それぞれに距離変換を掛ける
4. 差を取って符号付き距離にし、`SPREAD` で正規化して 0..1 に詰める

距離変換は Felzenszwalb の 1 次元アルゴリズムを行と列に 2 回掛ける。
近似ではなく**厳密なユークリッド距離**が O(n) で出る。

### 実装で効いた点

- **「無限遠」に `Infinity` を使ってはいけない。**
  グリフに触れない行はすべて未確定になり、`Infinity - Infinity = NaN` から
  以降が全部 NaN になる。テクスチャが真っ黒になり、何も描かれない。`1e20` を使う。
- **距離変換はセルごとに独立して掛ける。** アトラス全体でやると隣のグリフの距離が漏れ込む。
- **輪郭のすぐ際はサブピクセル補正する。**
  距離変換は格子点の距離しか出せないので、際が階段状に量子化される。
  拡大して縁取りを引くとギザギザとして出る。
  輪郭に接する画素だけ、アンチエイリアスされたアルファの被覆率
  （`a = 0.5` がちょうど輪郭）から距離を取り直すと消える。
- `DataTexture` は行 0 が `v = 0`（下端）。キャンバスは行 0 が上端なので、
  転送前に上下反転する。

## MSDF ではない

MSDF は**ベクタ輪郭**を 3 チャンネルに割り当てて、median を取ることで角を保つ手法。
ラスタ画像からは作れないので、ここでは通常の SDF。角がわずかに丸まる。

角の鋭さが要るなら `msdf-bmfont-xml` などで事前生成した png + json を読み込む。
シェーダー側は `median(r, g, b)` を距離として使うだけで、あとはこのまま流用できる。

## 文字単位の変形

頂点属性に「その文字の番号」と「その文字の中心」を持たせてある。
頂点シェーダーはこれを見て文字ごとに動かす。

- `reveal` — 番号に応じた時間差で立ち上げる
- `wave` — 中心の x を位相にして上下させる
- `glitch` — 番号と時刻のハッシュで横へ飛ばす

カーソルに近い文字は手前へ持ち上がる。

## 操作

- `text` に好きな文字列を入れると、その場でアトラスを焼き直す
- `Variant` で 縁取り / リビール / 波 / グリッチ
