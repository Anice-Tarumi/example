# Analytic Lighting

面積を持つ光源（球・管・矩形）と近接遮蔽を、**閉じた式だけ**で解く。
環境マップも LTC のルックアップテーブルもシャドウマップも使わない。
テクスチャは 1 枚も読まない。

## なぜ面光源が要るのか

点光源しか無い世界では、ハイライトは常に点にしかならない。
現実の光は必ず面積を持つので、蛍光灯は細長く、電球は丸く映り込む。
この「映り込みの形」が無いと、どれだけ PBR を積んでも CG っぽさが抜けない。

ふつうは次のどちらかで出す。

- IBL 用の環境マップを焼く → アセットが増える。動く光源には向かない
- LTC（Linearly Transformed Cosines）→ 2 枚の LUT が要る

ここは式だけで済ませる。光源は毎フレーム動かせるし、初期化コストもゼロ。

## 3 つの式

### 1. 拡散 — 球光源の放射照度

半径 r の球が距離 d にあるとき、面が受ける放射照度には解析解がある。

```glsl
if (cosTheta * cosTheta > sinSigmaSqr) {
  return PI * sinSigmaSqr * saturate(cosTheta);      // 光源が完全に地平線の上
}
// 地平線をまたいでいる場合。見えている部分だけを積分した式
float x = sqrt(1.0 / sinSigmaSqr - 1.0);
float y = -x * (cosTheta / sinTheta);
float e = sinTheta * sqrt(1.0 - y * y);
return (cosTheta * acos(y) - x * e) * sinSigmaSqr + atan(e / x);
```

点光源のように「真横で急にゼロ」にならず、光がふわりと回り込む。
影の縁の柔らかさはここから出る。

### 2. 鏡面 — MRP（最も寄与する代表点）

面光源を積分するかわりに、**反射ベクトルに最も近い光源上の 1 点**へ潰して
点光源として解く。ハイライトの位置と形は光源の形になる。

潰したぶん明るさが変わるので、粗さを広げて正規化して戻す。

```glsl
float widened = clamp(a + mrpRadius / (3.0 * dist), 0.0, 1.0);
float norm = (a / widened) * (a / widened);
```

管なら細長い筋、矩形なら四角い映り込みになる。

### 3. 遮蔽 — 立体角

半径 r の球が距離 d にあるとき、その球が張る立体角は

```
Ω = 2π (1 - cos α),   sin α = r / d
```

で閉じている。半球（2π）で割れば「空をどれだけ塞がれているか」がそのまま出る。
法線方向の余弦で重み付けして掛け合わせる。

シャドウマップと違って**影の形は出ない**。出るのは接地部分の締まり
（コンタクトシャドウ）で、`Proximity AO` variant で床を明るくすると
球の真下だけがすっと沈むのが見える。

## 管と矩形の扱い

拡散は「最近点にある球」で解くが、そのまま半径 r を使うと
**長さや面積の寄与が丸ごと落ちて暗くなる**。

シルエットの面積が等しい円板の半径に直してから解く。

- 管 … 幅 2r × 長さ 2L⊥ のスタジアム形 → `sqrt(r² + 4rL⊥/π)`
- 矩形 … 面積 × 光源方向との傾き → `sqrt(area·facing/π)`

これで球・管・矩形を同じ `power` で並べても明るさの桁が揃う。

## 近似であることの明示

- 鏡面の MRP は積分の代わりの近似。光源が非常に大きく、面に非常に近いときは
  ハイライトの形が崩れる。厳密にやるなら LTC。
- 遮蔽は球でしか近似していない。箱や板の遮蔽体を扱うなら、
  それぞれの立体角の式に差し替えるか、包む球で代用する。
- 相互反射は無い。光源から直接届く分だけ。

## 操作

- `shape` で 球 / 管 / 矩形
- カーソルを動かすと光源が寄る
- `proximity` を 0 にすると近接遮蔽が切れる。効き方はこれで比べる
