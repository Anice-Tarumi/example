# Stroke Growth

画面をドラッグすると、その軌跡に沿って茎が伸び、離すと花が開く。

元ネタは makemepulse 2019（Nomadic Tribe）の Scene 1。
Obsidian の 2 ノート（ドラッグストロークで植物を育てる / Catmull-Rom スプライン頂点変形）を
three.js に置き換えたもの。

## 3 段に分ける

```
入力（レイ × 傾いた平面）
  → スプライン（一定距離ごとにアンカーを蓄積 → 3 次係数へ展開）
    → 頂点変形（まっすぐな筒 1 本を曲げる）
```

この 3 段に分けておくと、見た目だけ差し替えられる。
蔓・ロープ・煙の尾・電撃・筆跡は全部これで作れる。

## ジオメトリは 1 本だけ

持っているメッシュは **z 方向にまっすぐ伸びた円筒 1 本**。全個体で共有する。

- `pos.z` → スプラインのパラメータ（0..1）
- `pos.xy` → 断面の座標

曲げるのは頂点シェーダー。ジオメトリの再生成もモーフターゲットも要らない。
**uniform を書き換えるだけ**なので、draw call もメモリも増えない。

## 係数を CPU で展開しておく

制御点をそのまま渡すと、頂点ごとに Catmull-Rom の基底行列を掛け直すことになる。
JS 側で 3 次多項式の係数（sp1..sp4）まで展開しておけば、シェーダーは
ホーナー法の評価だけで済む。分岐も行列積も無い。

```glsl
vec4 ppos = t * (t * (t * sp4 + sp3) + sp2) + sp1;      // 位置
vec3 ptan = t * (t * sp4.xyz * 3.0 + sp3.xyz * 2.0) + sp2.xyz;  // 接線（1 階微分）
```

`vec4` の `w` にはねじれ角を載せてある。位置とロールを 1 本の配列で運ぶ。

## 姿勢は平行移動フレームで作る

接線だけから法線を作る（Frenet 枠）と、曲率 0 の点で法線が飛ぶ。
節点ごとに up を持たせ、**直前の up を接線に直交化して運ぶ**。
シェーダー側はその up を節点間で補間して使う。

## 移植で効いた 4 点（元ノートの指摘そのまま）

1. **ピック平面を傾ける。** 真正面（`[0,0,1]`）だと茎が板に見える。
   `[0,-0.5,1]` を正規化した、カメラ側へ倒れた面を使う。
2. **生入力を指数スムージングしてからストロークへ渡す。**
   手ブレやフレーム落ちが曲線に出なくなる。
3. **進行度で追従係数を減衰させる。** `pow(1 - d, 0.6)` を係数にすると、
   伸びが上限に近づくほど詰まる。イージング関数を別に持たずに減速が出る。
4. **短すぎる入力は捨てる。** これを忘れるとクリックのたびに極小の花が量産される。

元実装は `6 * dt` を追従係数にしていて、これは厳密にはフレームレート非依存でない。
ここは `1 - exp(-6 * dt)` にしてある。

## uniform 配列の上限

`spline_iv` は `SEGS*4` 個の vec4、`spline_nrm` は `SEGS+1` 個の vec3。
WebGL1 の下限が 128 vec4 なので、実用上 16〜24 セグメントが限界。

元実装は 47 セグメントを 16 × 4 メッシュに分割して収めていた。
ここは 1 本のまま、**溜めた点列を毎フレーム SEGS+1 点へ取り直す**。
ドラッグで点がいくら増えても uniform の長さは変わらない。

## 元実装から落としたもの

- 花弁の開花は、元は 10 個のモーフターゲットを三角形の重みでブレンドしていた。
  ここは花弁ごとに角度と大きさを 1 パラメータで動かす簡略版。
- 成長速度に連動する音（ループ音を gain 0 で鳴らしっぱなしにして音量だけ動かす）は
  未実装。音を出す example の方針を決めてから入れる。

## 地面から生やす

根元は必ず地面の上に置く。押した位置は**地面の平面**へレイを落として決め、
ドラッグ面（カメラ側へ倒した平面）は**その根元を通す**ように張り直す。

```js
const root = pickOn(groundPlane, e.clientX, e.clientY)
plant.plane = new THREE.Plane().setFromNormalAndCoplanarPoint(PICK_NORMAL, root)
```

ドラッグ面を原点固定にすると、押した場所によって茎が地面から浮いて生える。
ドラッグ中は `y` を地面より下へ行かせない。

根元には放射グラデーションのテクスチャを 1 枚焼いて落ち影として敷く。
接地しているように見せるにはこれで足りる（影を落とすライトは要らない）。

自動デモの横揺れは立ち上がりで 0 に落とす。
根元でいきなり横へ飛ぶと「生えた」ように見えない。

## 操作

- ドラッグで茎が伸びる。離すか、一定以上伸びると咲き始める
- 触っていないと自動で生える（`auto` を切ると止まる）
- `Variant` で 花 / 蔓 / ネオン / 茂み
