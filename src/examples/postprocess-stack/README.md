# Postprocess Stack

`EffectComposer` も `UnrealBloomPass` も使わず、パスを 1 本ずつ `FullScreenQuad` で組んだ
ポストプロセス一式。

```
scene(HDR) ─▶ bright ─▶ down ─▶ down ─▶ down        (4 段のミップチェーン)
                 └─ 各段で分離ガウス 5 tap ─┘
                        ▼
              小さい段から加算しながら上げる
                        ▼
  composite: 色収差 → bloom 加算 → レンズゴースト/ハロー
             → 露出 → ビネット → ACES → sRGB → 3D LUT → グレイン
```

## 被写体と比較表示

ポストプロセスは**被写体が読めないと何をしているか伝わらない**。
発光する抽象形状に掛けても「光っているもの」にしか見えない。

そこで夜の街角を置いている。街灯・窓明かり・ネオン・車のヘッドライトなら、
効果がそのまま「光源の滲み」「レンズのゴースト」「時間帯の色」として読める。
効き目が出る条件は 2 つで、この被写体はどちらも満たす。

- 小さくて非常に明るい点（1 を大きく超える）がある → ブルーム / ゴースト
- 中間調が広くある                                 → グレードの効きが見える

さらに `compare` で画面を左右に割り、**左に素の絵、右にスタック適用後**を出す。
スライダーを 0 にすれば全面が適用後になる。

## なぜ自前で組むか

bloom も色収差もビネットも、単体なら公式 example で足りる。
ここで見せているのは **1 本のパイプラインとして順序と重みを制御できること**。

- 段ごとの重みを触れる（`falloff`）。小さい段だけ残せば霞、大きい段だけなら硬い滲み。
- ゴーストとブルームで**別のソースを引く**。累積ブルームは最小段の全画面の霞を含むので、
  それをゴーストに使うと画面いっぱいの色ムラになる。ゴーストは 1/2 段だけを見る。
- LUT を掛ける位置が選べる。トーンマップと sRGB 変換の**後**に置いている。
  カラリストが `.cube` を作るのは表示色空間なので、リニア値に掛けると意図が変わる。

## テトラヘドラル補間

3D LUT の引き方。ふつうの `sampler3D` の線形補間は三線形（立方体の 8 頂点の混合）で、
対角方向に LUT へ存在しない色が出る。

立方体を 6 個の四面体に割り、入力が属する四面体の **4 頂点だけ**を混ぜる。
どの四面体かは r,g,b の小数部の大小関係だけで決まるので分岐は 6 通り。
コントラストの強いグレードでもグラデーションが折れない。

そのためテクスチャのフィルタは `NearestFilter`。`LinearFilter` にすると
ハードウェアの三線形が先に掛かって、わざわざ四面体を選ぶ意味がなくなる。

LUT は `lut.js` でグレードを関数として書き、32³ の格子に評価して `Data3DTexture` に焼いている。
形式は実物の `.cube` と同じなので、読み込みに差し替えられる。

## 実装メモ

- **GLSL3 の `ShaderMaterial` に `gl_FragColor` は無い。** `layout(location = 0) out vec4` を
  自分で宣言する。GLSL1 では three が用意してくれるので、切り替えたときに気付きにくい。
- ゴーストは画面を 180 度回した像を中心基準で縮小コピーしたもの。
  **倍率が 1 付近を通ると中心の数テクセルが全画面に拡大される。**
  段ごとに 1 を跨がないよう離し、符号を交互に振る。
- RT は `ClampToEdge`。**画面外を参照したゴーストは端の 1 列が引き伸ばされて巨大な色面になる。**
  範囲外は重み 0 で捨てる。
- 段を素で足しているので、重みの総和で割って正規化する。
  しないと段数や `falloff` を変えるたびに全体の明るさが跳ねる。
- 金属面は環境マップが無いと真っ黒。反射させる相手（`Lightformer`）を置く。
- 発光の面積が広いとゴーストも巨大になる。光源は小さく、強く。
- 色収差は `uv - 0.5` の二乗に比例させるが、係数をそのまま使うと数十 px ずれる。
  実際のレンズは数 px の話なので 0.02 倍している。
