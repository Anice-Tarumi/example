# Flip Stage

忍者屋敷のどんでん返し。床が回転して裏返り、裏に隠れていた別のシーンが現れる。

盤面は**表と裏の 2 面しかない**が、返すたびに新しい景色が出てくる。

## 仕掛け

回転が 90 度を過ぎた瞬間、下を向いた面はもうカメラから見えない。
そこで **これから隠れる側だけ** を次のシーンに差し替える。

```
初期      top=森(上)   bottom=街      next=岩山
1回目返す  top=岩山     bottom=街(上)  next=氷      → 街が出る
2回目返す  top=岩山(上) bottom=氷      next=砂漠    → 岩山が出る
```

差し替えるのは常に「これから隠れる側」で、上がってくる面には触らない。
ここを逆にすると、返った直後に見えている面が書き換わって破綻する。

「幕が閉じている間に舞台を組み替える」という `scene-transitions` と同じ思想を、
物理的な回転でやっている。

## 実装メモ

- 全シーンをマウントしたまま `visible` を ref 経由で切り替える。差し替えで再レンダリングは起きない。
- 裏面の group は `rotation={[Math.PI, 0, 0]}` で貼る。返ったときに正立する。
- 円盤は y=0 対称に置く。非対称だと裏返ったとき円柱の蓋が地面より上に来て、地面を隠す。
- 地面の円は円柱の蓋と同一平面に置かない。z-fighting で放射状の縞が出る。
- **円盤の外周に地面板（`ringGeometry`）を敷く。** マンホールと同じで、
  裏側にぶら下がっているシーンが下から覗くのをこれで塞ぐ。
  「静止中は裏を非表示」では、一度返ると表に来た面まで消えるので使えない。
- 隙間から覗く分は `fogExp2` で沈める。
- イージングは `easeInOutBack`。等速だと仕掛けが安っぽく見える。

## 操作

- 床をクリックで手動フリップ
- `auto` で自動フリップ、`interval` で間隔
