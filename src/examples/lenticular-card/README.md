# Lenticular Card

かまぼこ型のレンズを並べた板の下に、N 枚の絵を短冊状に交互に印刷する。
レンズは真下の短冊を拡大して見せるが、**見る角度で拡大される位置がずれる**ので、
角度ごとに違う絵が見える。

## 式

```
θ … 視線が面の横方向へ寝ている角度
f … 焦点距離 / P … レンズのピッチ

s = tan(θ) · f / P          レンズが拾う短冊の位置
k = s を [-span, span] で正規化 → 0..N-1 のコマ番号
```

本体はこれだけ。難しいのは周り。

## 間違えた所

**1 本のレンズの中でコマを変えてはいけない。**
最初 `s = u + tan(θ)·f/P`（u はレンズ内の位置）と書いて、レンズ 1 本の中で
コマが変わる実装にしたら、画面が縦縞のノイズになった。

レンズは真下の短冊 **1 本**を拡大して見せる。だから **1 本のレンズ面は丸ごと
同じコマ**。コマを決めるのは視線角だけ。u はレンズの稜線の陰影にしか使わない。

**絵を引く位置はレンズの中心に量子化する。**
レンズ 1 本が短冊 1 本を拡大するので、**横の解像度はレンズの本数まで落ちる**。
実物が縦に櫛の目のように見えるのはこれ。滑らかに引くと、ただのぼけた画像になる。

## クロスフェードに見えないために要る 4 つ

1. **隣のコマの滲み。** レンズの開口は有限で、1 枚だけがきれいに見えることはない
2. **色収差。** チャンネルごとに屈折量を変える。切り替わり際の赤と青の縁。
   これが一番「レンチキュラーだ」と分かる手掛かり
3. **レンズの稜線。** 継ぎ目がわずかに暗い。縦縞が見えて初めて表面にレンズが
   載っていると分かる。ただし 1 本が数画素を切ったら消す（モアレになる）
4. **表面の艶。** 透明プラの鏡面。無いと印刷物にしか見えない

## 絵は起動時に 1 回だけ焼く

レンチキュラーは**印刷物が動かない**のが本質。毎フレーム角度に応じて描き直すと、
それはただの視差エフェクトで、特有の飛び（コマ落ち）とゴーストが出ない。

## 素材は 1 枚の絵を 4 層に分ける

**別々に生成した 2 枚を切り替えてはいけない。** 生成物は毎回構図が変わるので、
切り替えた瞬間に画が飛ぶ。同じ絵を層で分けて、層ごとに違う速さでずらせば、
構図ズレは原理的に起きない。

- A 背景（光条と塵）… 視差 1.00
- B クラゲ … 0.55
- C チョウチンアンコウ（主役）… 0.15
- D 海藻と岩（手前）… **−0.30（逆向き）**

**手前を逆に動かす**のが効く。全部が同じ向きだと、絵が丸ごと平行移動している
だけに見える。

生成された層はどれも画面いっぱいに描かれてくるので、**構図はシェーダー側で
組む**（大きさと位置を層ごとに与える）。そのまま重ねると、巨大なクラゲと巨大な
魚が重なっただけの絵になる。

イラストは自作（生成）。配布物は使っていない。

## 変わるのは視差だけではない

視差だけだと「同じ絵が少し動く」で終わる。角度で**光の状態**も振る。

- 片端 … 上から光条が差し、クラゲがよく光る
- 反対の端 … 光が落ちて色が抜け、**アンコウの提灯だけが暖色で残る**

無関係な隠し絵を出すより、同じ絵の中で状態が変わるほうが意味が通る。
暗くするだけでは「暗い同じ絵」になるので、彩度も一緒に落とす。

## 絵の作り方の制約

横の解像度がレンズの本数まで落ちるので、**小さくて明るい要素は角張った白い箱**に
なる。実物のレンチキュラー印刷で細かい柄を避けるのと同じ理由。
大きめ・柔らかめ・暗めに作る。

## 視線角の出し方

**外から角度を渡さない。** 実際の視線から計算する。

```glsl
vec3 view = normalize(cameraPosition - vWorldPos);
float theta = asin(dot(view, vTangentW));
```

こうするとカードを傾けてもカメラを動かしても正しく効く。画素ごとに少しずつ
違うので、大きな板だと**帯**になって波が走る。実物で見える横帯の正体。

## 操作

- ポインタ … 疑似的な視線角
- `deviceorientation` … 実際に端末を傾ける。**iOS は `requestPermission()` を
  ユーザー操作の中で呼ぶ必要がある**ので、ボタンを出す以外の方法が無い

## できないこと

左右の眼に別の絵を届けるのは無理。実レンズか裸眼立体視ディスプレイの領分。
**片眼で見たときの見え方**の再現に留まる。
