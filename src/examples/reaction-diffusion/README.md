# Reaction Diffusion

Gray–Scott 反応拡散。2 種類の物質 A と B が格子の上で広がって反応する。

```
A' = A + (Da ∇²A − A B² + f (1 − A)) Δt
B' = B + (Db ∇²B + A B² − (k + f) B) Δt
```

Da = 1.0、Db = 0.5、Δt = 1.0。ラプラシアンは 3x3（中心 −1、上下左右 0.2、斜め 0.05）。
値は Karl Sims の解説（https://www.karlsims.com/rd.html）で確認した。

| 模様 | f | k | 出典 |
|---|---|---|---|
| Coral | 0.0545 | 0.062 | Karl Sims |
| Mitosis | 0.0367 | 0.0649 | Karl Sims |
| Maze | 0.029 | 0.057 | 画面で確かめて決めた |

## 踏んだ所

**状態は浮動小数で持つ。** 8bit だと 1 回の変化量が 1/255 より小さく、丸めで増減が
消えて模様が育たない。

**B = 1 の小さな点を種にしない。** Mitosis の係数では育つ前に拡散で薄まって全滅した
（画面が真っ黒）。Pearson の論文と同じく、種の中を A = 0.5 / B = 0.25 にして雑音を
足すと、どの係数でも立ち上がる。筆も同じく A を下げる。

**leva の step を粗くしない。** leva は min から step 刻みへ値を丸める。0.0005 刻みで
Mitosis の 0.0649 が 0.065 に、0.0367 が 0.0365 に化け、それだけで模様が全滅した。
0.0001 刻みにする。表示桁は `pad` で 4 桁に（既定は 2 桁に丸める）。

**ラプラシアンを上下左右の 5 点で取らない。** 格子の向きが模様に出て、縦横に揃った
筋が伸びる。斜めも入れると等方に近づく。

**1 フレーム 1 回では遅い。** 十数回まとめて進めないと、触っても何も起きないように
見える。

## 見せ方

濃度をそのまま色にすると緑と黒の教科書の絵になる。**B を高さとみなして法線を出し、
光を当てる。** 描かれた柄ではなく、盛り上がった物質に見える。法線は 1.5 テクセル
離して取る（隣同士だと格子の段が面に出る）。

## Parameter map

横に f、縦に k を振って、1 枚に模様の分類を並べる。**範囲は Sims の図より狭めた。**
全域（f 0.01–0.1 / k 0.045–0.07）だと右下が B で飽和した平面、左上が消滅した黒に
なり、画面の半分以上が何も起きない。f 0.014–0.056 / k 0.053–0.067 に寄せると、
斑点 → 虫 → 迷路 → 穴 → 飽和、の遷移が帯で並ぶ。

地図のときだけ**端を巻き戻さない**。巻き戻すと feed 最大の右端と最小の左端が隣り合い、
縁に筋が立つ。種は全面に撒く（種の無い所は何も育たない）。
